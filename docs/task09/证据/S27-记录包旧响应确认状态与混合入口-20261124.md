## 3. 修复内容

### 3.1 前端：单调请求代次（对齐本仓既有口径）

- 两个 hook 改为 **`useReducer` ＋ `requestIdRef`**（与 `use-local-runtime-status.ts`／`use-local-backup.ts` 同款）：
  - 每次请求递增序号；**成功／失败两条回写路径都核对序号** ⇒ 旧响应的结果与失败都丢弃；
  - `reset` 同样递增序号 ⇒ 关闭／换包后旧响应不再复活状态；
  - 状态里带 `requestId`，**旧响应不覆盖当前选择**。
- 面板换包即失效：导入面板路径 `onChange` ⇒ `reset()`（旧预检结论与确认入口当场消失）。
- 确认绑定可见化：导入面板在预检结论里展示**该轮预检的包路径**（用户看得到自己确认的是哪个包）。

### 3.2 前端：确认动作的正确形态

- **副作用移出状态更新函数**：确认改为"读最新状态镜像 → 发起请求 → 按序号回写"，
  updater 恢复为纯函数（StrictMode 不再双发）。
- **双击互斥用同步闸门**（`importingRef`），不依赖 React 渲染快照（同一批次两次点击看到的仍是旧状态）。
- 确认按钮在导入中禁用并显示 loading；`onConfirm` 返回 Promise ⇒ 弹层在导入完成前保持开启（不再"点了没反应"）。

### 3.3 后端：混合形态与旧形态同一闸门

- core 新增 `normalizeExportEntries`（`record-package-export.policy.ts`）：非空、逐条资源类型白名单、
  逐条正整数、按（资源类型＋记录 ID）去重、去重后条数 ≤ `EXPORT_RECORD_IDS_MAX`；
- `export-record-package.usecase.ts` 的 mixed 分支改走该闸门 ⇒ **混合不再是绕过受控上限的旁路**；
  旧单类型分支保持原口径（旧客户端不受影响）。

## 5. 已知边界与遗留

1. **导入批次级互斥未加**（D8）：服务端 `importRecordPackage` 没有"同批次只跑一次"的闸门，
   并发双击仍存在两个实例同时进入逐条循环的窗口。**未加的原因**：批次 `RUNNING` 条件更新会与
   既有"中断重试：已成功的条目不重做"语义冲突（中断遗留的 `RUNNING` 批次必须允许重跑）。
   现有幂等事实：逐条终态跳过 ＋ 回执唯一键 ＋ writer 的 `DUPLICATE` 判定。
   本轮把**客户端双击**收敛为一次请求（同步闸门 ＋ 按钮禁用），服务端并发窗口如实登记为遗留。
2. **来源页导出对话框的 mixed 分支生产不可达**：来源页仍只支持单类型导出；
   混合导出的正式入口在记录包独立页（`/engineer/record-packages`）。本轮只核对并如实登记，未扩大范围。
3. **浏览器反例仍为 mock-only 纪律**：本仓前端 e2e（Playwright）按既有纪律是 mock-only；
   本项的"真实入口"证据来自后端隔离实库（真实 API ＋ 真实落盘 ＋ 真实逐条授权），
   前端侧以 hook／组件级定向用例覆盖旧响应与确认状态。
4. **前端全量并发跑的失败属环境性**：本机一次性全量并发跑时，多个与本轮无关的套件超时失败
   （耗时 5–21 秒，典型超时）；受影响的 41 个套件单独跑 **602/602 全通过**。
   该现象已如实登记，未改断言、未粉饰；后续应在前端 CI 环境复跑全量确认。

## 7. 补充（第 06 项续做）：切账号使在途响应失效

- **实现**：两个 hook 接受 `sessionKey`（当前会话的账号标识），**变化时递增请求序号并回到空闲**
  ⇒ 旧账号的在途响应（导出／预检／导入）一律丢弃，不会写进新账号的界面；
  导出／导入面板与导出对话框接收 `sessionKey` prop，
  页面（`pages/record-packages`、`pages/my-records`）从 `useAuthSession()` 取账号标识传入
  （层级合规：pages → features；features 之间不直接互相依赖）。
- **用例**：新增 2 例——导出 hook「切账号：在途响应对旧账号作废」、导入 hook「导入中重置：在途导入成功响应不写回」；
  记录包前端 **6 套件 / 25 用例全通过**。
- **未单列（如实登记）**：组件层「关闭重开」未单列断言（antd Modal 关闭即卸载、重开为新实例），
  该语义由 hook 层 `reset` 用例（reset 后旧响应不回写）覆盖。
