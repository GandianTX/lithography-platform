- **对齐前的保护措施**（计划第 01 项"必要时先保护现有工作再按授权对齐"）：

  4. `git stash push -u -m "task09-align-before-rebase-20261123"`。
- **对齐方式的选择**：`git rebase fork/main` 走的是 `--fork-point`（分叉点＝旧 `fork/main` ＝ `b88a10d`），
  会把**合并 main 之前的任务 09 提交**也逐个重放 ⇒ 在 `enum.registry.ts`／`lithography.module.ts`
  与任务 10 的改动冲突（已 `git rebase --abort` 放弃，未留下任何改动）。
