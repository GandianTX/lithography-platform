```

```

**开发库 `lithography_task09_dev` 的既有账号（73 行）仍为 NULL**：它们由
`database:deploy --dev-accounts-file` 在本轮改动**之前**建号，属"历史行"，
按设计**不回填**。这意味着开发库账号在跨安装判定中走**账号名＋公司**映射路径
（依据 `LOGIN_NAME_IN_COMPANY`），而 e2e/Seed 库走**稳定标识**路径
（依据 `STABLE_ID`）——两条路径都有定向测试覆盖。
