**"不能推断已同步"逐条落地（策略层断言）**：

| 场景 | 断言 |
| --- | --- |
| 身份不可信（无可信 UUID） | `身份不可信时返回 UNKNOWN，不得用派生键冒充可信键` |
| 版本不可信（草稿版本 0） | `版本不可信时返回 UNKNOWN` |
| 仅任务成功但**缺回执** | `仅任务成功但缺少回执时不得判已同步` |
| 回执版本与当前版本不一致（旧响应） | `回执版本与当前版本不一致时不得判已同步` |
| 回执摘要／正文／原件不完整 | `回执缺摘要、正文或原件不完整时不得判已同步` |
| 回执来源不是本机 | `回执来源无法确认是本机时不得判已同步` |
| 任务与回执互相矛盾 | `任务与同版本回执互相矛盾时按未知处理` |
| 适用性无法判定 | `适用性无法判定时返回 UNKNOWN，不得由缺任务推断` |
| 未装配实现 | `未装配实现时返回 NOT_CONNECTED（未接入不是同步结果）` |

**范围与批量**：跨公司记录**不返回条目**（不泄露记录是否存在）✔；批量超上限**明确拒绝**✔；
空请求返回空结果✔；本机未映射云端组织时返回空条目✔。

**冲突入口**：`canResolveConflict` 只在"冲突可读**且**可处理"时给出；不可读时**不给出**冲突标识与处理入口✔。

### 缺口与处置

| 缺口 | 性质 | 处置 |
| --- | --- | --- |
| **"保留本地"只支持工单** | **真实缺口（G10）** | 见下方"为什么本轮不做" |
| **"使用云端"只落 `decision` ＋ 确认人，未把本地有权视图对齐到云端内容** | **真实缺口**（R068 明写"UPDATE 本地当前视图"；`sync_conflict` 同时存 `local_snapshot` 与 `cloud_snapshot`，云端内容本机可用） | 本轮**未实现**：对齐需要来源域的受控写回（"以云端内容生成新版本"语义），而该入口当前只接受"本地快照载荷"；补齐须扩载荷映射 ＋ 快照契约，属跨域结构性变更 → **登记为待办**，不虚报通过 |
| 不可写对象（报告、资料）**显式拒绝**并给出原因 | **符合要求**（"不可写对象只读、明确原因"） | 无需改动 |

**为什么"保留本地"扩到资料在本轮不可验证地完成**（不以任务编号搪塞）：

1. **载荷来源不存在**：冲突的 `local_snapshot` 由**冲突登记方**写入；本仓业务同步接收端尚未实现（第 12 项），
   资料类冲突**没有任何生产者** ⇒ 资料快照的字段形状**无人定义、无人产出**。
   没有生产者的前提下定义并实现资料载荷映射，只能自造夹具，无法取证。
2. **权限口径不匹配**：资料修订入口只认**资料域的一级管理员事实**；09 的保留本地走
   **管理员文档库切片**权限 ＋ `resolveAdminOrganizationScope`。两套范围不同，
   叠加第二套权限规则会制造两套口径（策略层明令禁止）。
3. **跨域边界不存在**：`usecases → usecases` 只允许同域一跳。管理员文档库域**没有**资料受控修订入口
   （只有工单相关），资料修订入口在资料域。要打通需引入**中立端口**
   （如本仓恢复链的 `LOCAL_RESTORE_RECORD_WRITER` 模式）＋ 资料域实现 ＋ 快照契约扩展——结构性变更。

⇒ 结论：**第 08 项的"适用资源"＝工单**（有受控入口、有载荷来源、已实现并有测试）；
资料与报告**如实拒绝**并给出可读原因；资料扩展的**前置条件**已在上表列明（先有冲突生产者与中立端口）。
