### 2.1 链路（两段执行，中间用交接文件传递事实）

```
设备 A（NODE_ENV=development）
  1) 夹具：真实原件字节（PDF 头 + 随机正文）→ storage.save → insertStagedFile
           → insertReport(HISTORICAL_CASE, SUBMITTED, recordUuid, currentVersionNo=1)
           → insertVersion(SUBMIT, payload)
           → bindStagedAttachmentToReport（与导入写入**同一代码路径**）
  2) 导出：ExportRecordPackageUsecase.execute({session, targetPath, resourceType:'MAINTENANCE_REPORT', recordIds:[reportId]})
           → 产出含**真实原件字节**的包目录 + manifestChecksum
  3) 交接：写 JSON（packageId / packagePath / manifestChecksum / recordUuid / organizationId / originalChecksum / originalByteSize）

[把包目录复制到设备 B 可见的路径 —— 这就是 U 盘介质]

设备 B（NODE_ENV=e2e）
  4) 检查：CheckRecordPackageUsecase.execute({session, packagePath}) ⇒ 逐条资格（**预检不写库**）
  5) 导入：ImportRecordPackageUsecase.execute({session, packageId, packagePath, manifestChecksum}) ⇒ 逐项结果
  6) 读回核对（断言）：
     记录 UUID 一致 / 作者＝900101（作者与责任工程师均未被替换成导入人）/ 公司＝org 1 /
     版本＝1 / 状态＝SUBMITTED / 正文标题一致 / 原件**字节摘要**与 A 侧一致 / 原件字节数一致
```

### 2.2 实现要点（下一轮直接照做）

| 要点 | 做法 |
| --- | --- |
| 装配 | 用 `Test.createTestingModule` 引入 `ConfigModule.forRoot({envFilePath:['env/.env.<NODE_ENV>','env/.env.development']})` ＋ `DatabaseModule` ＋ `TypeOrmTransactionModule` ＋ `LoggerModule` ＋ `LocalReferenceDocumentStorageModule` ＋ `LocalRuntimeStorageModule` ＋ `LocalRuntimeUsecasesModule` ＋ `MaintenanceReportUsecasesModule`；业务模块自带 `TypeOrmModule.forFeature` |
| 架构守卫 | `scripts/` 属受控 wiring，读 `process.env` 与 `ConfigModule` 需 `// eslint-disable-next-line local-architecture/no-runtime-config-outside-wiring`（照 `scripts/seed-mock.ts` 写法） |
| 类型安全 | `dataSource.query()` 返回 `any` ⇒ 统一走一个 `queryRows<T>()` 助手收口（`as unknown as T[]`），避免 `no-unsafe-assignment` |
| 夹具枚举 | 用 `MaintenanceReportSourceType` / `MaintenanceReportStatus` / `MaintenanceReportChangeKind` 枚举常量（不要裸字符串） |
| 公司 id | **按组织编码查**（`organization_code='CLIENT_DEFAULT'`），不猜 id；两库实测均为 1 |
| 会话 | 直接构造 `UsecaseSession`（`accountId=900101`、ENGINEER），**不经过登录**（登录是 HTTP 面，另由 Playwright 覆盖） |
| 清理 | 用 `test/utils/e2e-scoped-cleanup.ts` 的台账式精确清理（只删本轮登记的行），**不 TRUNCATE** |
