## 7. 与计划差异（需 B 知悉）

计划命令示例使用 `--env-file`。实测 Node 20.6+ 原生支持 `--env-file` 并在脚本启动前拦截该参数：文件缺失时由 Node 直接以 `env/.env.missing: not found` 退出（exit 9），本入口无法给出“环境文件不存在”的明确失败，M01 契约无法满足。因此正式入口改用 `--config-file`，语义完全一致（显式、缺失即失败、不回落），并已在操作说明与 README 注明。这是规避原生参数冲突，不是放宽校验。
