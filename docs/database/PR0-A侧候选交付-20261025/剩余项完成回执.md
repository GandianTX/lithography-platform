### 3.1 Seed 非 Mock 对照的方法

在私有新实例插入合成账号、用户信息、PEER 组织、已 LEFT 成员、禁用机型，以及正文与软删文件资料。对照记录不在 900000—999999 Mock 保留主键段，内容和自然标记与 Mock 不同。

完整 Seed 每轮退出0后，用相同精确 ID 执行 `SELECT *`，比较两轮后的全部字段（包括时间、状态、JSON、外键和软删/文件引用）与执行前快照；同时比较两轮后全部23表的行数向量。不仅比较“Seed 打印成功”或数据库总条数。此处文件引用是合成文本，不是真实上传文件。

production 契约验证保持 API 使用 E2E 隔离配置，只让实际异常过滤器读取 production 判定，并用读取计数证明请求确实进入该分支；它不代表真实生产部署验收。实际四条 DomainError 响应仍携带细错误码，符合当前“细码可省略，而非必须省略”的契约；前端对缺失细码的降级由本轮适配器单测验证，不冒称服务器已经隐藏细码。
