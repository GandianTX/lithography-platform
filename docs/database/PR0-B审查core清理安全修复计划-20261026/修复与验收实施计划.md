## 3. 必须实现的安全不变量

### I1 环境与操作授权

- 每个破坏性清理入口独立核对显式物理清理许可、预期E2E目标及SELECT DATABASE()实际连接结果；前一层做过不能替代本入口。
- 无许可、错预期库、实际连接不符，在第一条DELETE前拒绝。
- 关闭全局清库开关不等于规格自身不会整表删除；不得把E2E_SKIP_DB_CLEANUP当作全部清理安全开关。
- 业务数据库备份、B故障现场和生产/共享库禁止作为测试目标。

### I2 本轮目标及预期事实

- 创建成功后立即登记真实ID；beforeAll中途失败也能精确找到已成功创建部分。
- 账号、userinfo、成员及相关业务行按本轮创建证据和预期关键字段核验；不能仅凭固定ID范围、loginName/email前缀或“看起来像测试数据”删除。
- 测试会合法修改角色/状态等字段时，由该次受控测试操作显式记录预期变化；不能在清理时读取当前值并直接当作预期值。
- 优先不复用同名账号；碰撞时先拒绝。不使用“先删除同名数据保证测试能跑”的方式。
- 必须恢复残留时，另走完整指纹及父子关系验证；自然键只能定位候选。不能把B本次残留简单交给新清理器无条件接管。
- 1:1用户资料等可验证从属关系单独说明；不能把“关联本轮账号”自动等同“此账号下所有记录都是本轮所有”。

### I3 首删前完成全量预检及引用闭包

- 对全部目标先核验存在性、预期字段、父子链和集合外引用，必要根行锁定。
- 资料创建人/更新人、组织成员、投稿附件/版本/审核、维修申请/回复、第三方绑定、验证记录等引用逐项核对；本轮不拥有的引用必须拒绝，不能顺便纳入删除。
- 非本轮账号或其资料引用不在目标集合中时保持不变；若外部记录引用本轮待删目标，必须在第一条DELETE前拒绝。
- 不复用runGuardedScopedCleanup的任意回调来包裹原整表删除后宣称已经获得行级/事务保护。

### I4 单事务原子清理

- 本次批量清理涉及的子表、成员、userinfo和账号在同一事务内预检、删除、提交。
- 仅按已验证真实ID及关联键精确删除，按实际外键依赖顺序执行。
- 后续DELETE失败，前序DELETE必须回滚；不能把各表分别调用多个事务后视为整个批量原子。
- 没有归属的整表删除即便加事务也不合格；只有WHERE而无所有权证明也不合格。
- 空目标应无DELETE，保持现有空集合安全行为，不生成IN()或退化成全表操作。
- 所有权台账仅在清理事务确认提交后清空或更新；回滚、结果未知或诊断失败时保留台账及失败状态，不能提前标记已清理。

### I5 收尾与错误可见

- 统一beforeAll/beforeEach/afterAll，避免重复清理；初始化失败后只清已登记资源，仍关闭应用/连接并恢复环境变量。
- cleanup失败必须使规格失败，不能只warn/error；finalize/close失败不得覆盖先前清理主因。
- 测试体或初始化失败与afterAll错误分别可见；原始失败不能被新错误或假成功遮盖。
- 诊断记录helper、阶段、资源类别、脱敏ID/数量、事务回滚情况和准确残留；不输出密码、Token或真实资料。

## 4. 受保护工具的最小扩展方向

现有ledger支持账号、组织、成员、投稿、正式资料和机型，尚未直接表达本轮几个历史规格的维修申请、回复、验证记录、第三方绑定。

S1先核对它们真实实体、FK与测试创建路径；S2优先在现有测试清理工具中增加必要的窄类型、归属事实和删除计划，或提取共用的“manager内预检+精确删除”步骤供同一事务编排。不建通用数据库清理引擎，不新增业务Entity/Migration。

必须说明以下关系：

| 资源 | 所有权与闭包要点 |
| --- | --- |
| userinfo | account_id关联已核验的本轮账号；预期资料事实核对，不能全表删 |
| membership | 同时核验组织/账号与该成员关系；不能只因账号在范围内就删除外部组织成员关系 |
| 验证记录 | 登记创建返回ID及类型/操作者/目标等实际字段；不能只按目标账号或类型全删 |
| 第三方绑定 | 登记绑定ID及本轮归属字段；不能clear整表，也不扩大到外部认证业务 |
| 维修申请 | 登记实际创建ID、账号和型号关系；外部申请不能因型号或客户相同被接管 |
| 工程师回复 | 精确回复ID与本轮申请/参与人关系；集合外回复需拒绝 |
| 设备型号 | 核验本轮创建/可信残留，外部资料/申请引用时拒绝；固定42等不代表本轮所有 |

复用现有工具前须核实它的自动扩图是否会纳入未登记的外部记录；不能假定旧安全工具天然满足新增资源语义。调整共享规则后，以完整core回归已有04/09/10/11/12消费者，不擅自放宽它们原有保护。
