### 6.1 授权前置（M02）

- beforeAll 在应用启动和副作用前捕获执行者许可及原始名单，要求许可恰为 `1`；缺失、0 或非法值，拒绝并释放已分配资源，不创建、删除或造数。
- 删除无条件自设许可。受控故障测试可以临时撤销/恢复已经验证的许可，必须恢复原值；不能从未授权状态升级。
- 主库预期/实际与名单保持核验。局部探针名单只服务于已授权、可证明本轮创建的目标，不能扩大名单接管既有库。

### 6.2 创建与归属（M01）

- 本轮优先保留固定探针名，改为不带 `IF NOT EXISTS` 的 CREATE，移除前置 DROP。碰撞原子拒绝，不能靠“先查不存在”认领。
- 只有 CREATE 明确成功后登记本轮归属和目标事实；碰撞、明确失败或结果未知均不得凭“现在查得到库”自行认领删除。
- CREATE 成功后的克隆/连接/造数失败，按已知归属精确清理；DROP 确认成功才能标记完成。未知与失败保留诊断，不假称零残留。
- 固定名碰撞允许失败关闭，不为自动重跑新增通用锁框架。唯一名作为备选也必须满足同等归属及未知结果规则。
- MySQL DDL 不与行删除共用“事务可以全部回滚”的承诺。连接不可用或目标不可信时，保留可诊断状态，不另开高权限旁路强删。

### 6.3 收尾与错误（M03）

- 释放 shifted 连接、清理本轮探针、恢复环境、关闭 app 各自独立尝试；一个步骤失败不跳过其余步骤。按实际依赖保持执行 DROP 的主连接在 DROP 尝试后关闭。
- 可以复用 `runE2eTeardown`，但不能把多个独立动作塞进一个首错即停的 callback，然后宣称都已保护。
- app/连接对象一旦分配即保存可释放引用。初始化中断、未获许可、CREATE 碰撞也须关闭已分配资源；未获得归属的资源不删。
- 保留 beforeAll/测试体错误与收尾错误；不只 warn 后绿色，也不以最后一个异常覆盖主因。测试不得依靠 `forceExit` 掩盖句柄未释放。

## 7. 组合验证与证据矩阵

H01—H09 的详细触发和断言沿用专项计划，不另改编号。以下是整个修复包必须覆盖的闭环。

| 验证组 | 最小场景 | 必须观察到的结果 | 证据层级 |
| --- | --- | --- | --- |
| E1 异主保留与碰撞 | 非本轮账号/info/成员/参考资料；同名探针库及非夹具记录；外部引用指向目标 | 非目标内容保持不变；不接管、不扩删；引用不符在首次删前拒绝 | 真实隔离 MySQL + 前后快照；H01 |
| E2 授权和目标 | 原许可缺失/0/1、配置错库、真实单会话 USE、事务 manager 不符 | 拒绝路径零危险副作用；正常路径保留原 G04/G04b 目标一致性断言 | 真实子进程/会话；H02/H03 + 定向守卫测试 |
| E3 事实和原子性 | 归属字段漂移、预期快照被外部修改、第二或后续 DELETE 失败 | 拒绝或整批回滚；同一注错下无事务负对照必须在快照断言失败 | 真实事务；保留原 D2，不用只检查报错消息替代回滚 |
| E4 创建与 hook 组合 | 第一账号已提交登记，第二账号在真实创建事务关键点失败，真实 beforeAll 失败后执行 afterAll | 第二笔无半成品，第一笔按台账回收；主错误可辨、关闭确实尝试 | 在现有 D1 子规格扩展同一共享 seed；父进程独立查询账号及 info、核对子进程日志与退出码 |
| E5 部分初始化/不可用 | CREATE 前拒绝；CREATE 后克隆或连接失败；台账非空且 DS 不可用 | 未拥有不删；已知本轮资源可精确收尾；无法完成时台账/失败保留 | H04/H05 + lifecycle 现有回归 |
| E6 未知及多重收尾 | CREATE/DROP 响应未知；destroy/DROP/close 单点及组合失败 | 不猜归属、不伪报成功；剩余释放仍尝试；原始及后续错误保留 | 精确调用点替身/注错，标注证据边界；H06—H08 |
| E7 重跑及竞争 | 清理成功后重跑、另一运行占用同名库、上轮有未决失败 | 不删除别人的资源、不重置未决台账；安全拒绝与正常重跑可区分 | H09；至少真实碰撞；竞争调度替身单独标注 |
| E8 最终交付 | 定向规格、适用消费者、完整 core 两轮、两链 39 样例、DB/文件夹具与非夹具 | 同一稳定候选实际通过；本轮残留和既有数据分别核对；无隐藏 skip、失败或证据替代 | 正式 runner，最终回执索引与必要脱敏摘要 |

负对照只在临时副本、隔离环境运行：分别恢复“先 DROP”“自行授权”“收尾首错中断”“无事务”等关键机制，要求对应断言失败；恢复正确实现后通过。可以复用当前候选已有且可回读的同命题负对照证据，不机械增加数量。

不是所有异常都需要真实制造网络故障或杀服务。H01/H02/H03、真实事务、D1 hook 必须有真实入口证据；结果未知及罕见关闭故障可用精确注错验证分支，明确不能外推为已经实测真实断网恢复。
