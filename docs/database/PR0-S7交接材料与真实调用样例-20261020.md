## 三、全链路变量序列与真实响应（39 条样例摘录）

> 变量均为逐字可复制；响应只摘关键字段（完整原文含全部时间戳，见 §1.1 重跑落盘）。
> 路径 B 账号替换：下例「工程师」= `mock_engineer_chen`（900_101），「管理员」= `mock_super_admin`（900_001）；路径 A 对应夹具账号。

### 3.1 A 链：资料投稿（MATERIAL，工程师建稿 → 管理员审核发布）

#### A1 建稿与改稿（DRAFT）

**A1.1 `createContentSubmissionDraft`** — 变量：

```json
{
  "input": {
    "kind": "MATERIAL",
    "fields": {
      "title": "S7 样例：光源能量校准作业手册",
      "documentType": "MAINTENANCE_GUIDE",
      "contentText": "S7 样例如正文 v1：1. 读取能量曲线；2. 执行校准；3. 记录结果。",
      "description": "S7 样例说明：适用于年度校准场景。",
      "equipmentModelText": "NXT:1980Di（手填）"
    }
  }
}
```

响应：`{ "id": 1, "submissionKind": "MATERIAL", "status": "DRAFT", "updatedAt": "…" }` → **记下 `submissionId = 1`**。

**A1.2 `updateContentSubmissionDraft(id: 1)`** — 机型文字→ID 同补丁替换：

```json
{
  "id": 1,
  "input": {
    "patch": {
      "description": "S7 样例说明（已更新）：覆盖年度与季度校准场景。",
      "equipmentModelText": null,
      "equipmentModelId": 47
    }
  }
}
```

响应：`{ "id": 1, "submissionKind": "MATERIAL", "status": "DRAFT" }`。要点：`equipmentModelText: null` 与 `equipmentModelId` 出现在同一补丁（互斥字段的替换语义）。

**A1.3 `myContentSubmission(id: 1)`**（改稿后回读）— 变量 `{ "id": 1 }`。
响应关键：`status: "DRAFT"`、`material.equipmentModelId: 47`（替换已生效）、`material.equipmentModelText: null`、`currentRevisionNo: 0`、`faultCase: null`、`currentAttachment: null`、`latestReview: null`、`publishedDocument: null`。

**A1.4 `myContentSubmissions`**（标题模糊筛选）— 变量：

```json
{
  "pagination": { "mode": "OFFSET", "page": 1, "pageSize": 10, "withTotal": true },
  "filter": { "title": "光源能量校准" }
}
```

响应关键：`items[0] = { id: 1, title: "S7 样例：光源能量校准作业手册", status: "DRAFT", currentRevisionNo: 0 }`、`total: 1`、`page: 1`、`pageSize: 10`。

#### A2 附件与送审（DRAFT → PENDING_REVIEW）

**A2.1 REST 上传附件** — `POST /api/content-submissions/1/attachment`，`multipart/form-data` 字段 `file`（示例文件名 `s7-sample-attachment.txt`，29 字节）。
响应（HTTP 201）信封关键：`{ "success": true, "data": { "attachmentId": 1, "originalFilename": "s7-sample-attachment.txt", "mimeType": "text/plain", "byteSize": 29 } }` → **记下 `attachmentId = 1`**。

**A2.2 `myContentSubmission(id: 1)`**（当前附件回读）— 响应关键：`currentAttachment: { "id": 1, "originalFilename": "s7-sample-attachment.txt", "mimeType": "text/plain", "byteSize": 29, "uploadedAt": "…" }`。

**A2.3 `submitContentSubmission` 未确认入库告知（失败样例）** — 变量：

```json
{ "id": 1, "input": { "libraryNoticeConfirmed": false } }
```

响应：`errors[0].extensions = { "code": "BAD_USER_INPUT", "errorCode": "CONTENT_SUBMISSION_INVALID_PARAMS", "errorMessage": "送审前请确认入库告知" }`（HTTP 200 + 错误数组）。

**A2.4 `submitContentSubmission`（冻结 v1）** — 变量 `{ "id": 1, "input": { "libraryNoticeConfirmed": true } }`。
响应：`{ "submissionId": 1, "revisionId": 1, "revisionNo": 1, "status": "PENDING_REVIEW" }` → **记下 v1 `revisionId = 1`**。

**A2.5 REST 待审上传被拒（失败样例）** — `POST /api/content-submissions/1/attachment`（`blocked-while-pending.txt`）。
响应：HTTP **409**；信封 `data = { "statusCode": 409, "code": "CONTENT_SUBMISSION_STATE_NOT_EDITABLE", "message": "当前状态的投稿不可编辑" }`。

**A2.6 `contentSubmissionRevision`（v1 冻结快照）** — 变量 `{ "submissionId": 1, "revisionNo": 1 }`。
响应关键：`revisionId: 1`、`schemaVersion: 1`、`titleSnapshot`、`payloadSnapshot`（6 字段，`equipmentModelId: 47`、`equipmentModelText: null`）、`attachment.id: 1`、`noticeVersion: "library-internal-v1"`、`confirmedAt` / `submittedAt`、`review: null`。

#### A3 审核队列 / 退回 / 重提（管理员协助）

**A3.1 `reviewContentSubmissions`**（审核队列·缺省待审）— 变量：

```json
{
  "pagination": { "mode": "OFFSET", "page": 1, "pageSize": 10, "withTotal": true },
  "filter": { "title": "S7 样例" }
}
```

响应关键：`items[0] = { id: 1, status: "PENDING_REVIEW", currentRevisionNo: 1, lastSubmittedAt: "…" }`、`total: 1`。

**A3.2 `reviewContentSubmission(id: 1)`**（审核详情）— 响应关键：`submissionId: 1`、`submittedByAccountId`（投稿人账号）、`currentRevision`（同 A2.6 快照 + `review: null`）、`reviewHistory: []`。

**A3.3 `reviewContentSubmissionDecision` 退回缺意见（失败样例）** — 变量：

```json
{ "input": { "submissionId": 1, "revisionId": 1, "decision": "RETURN" } }
```

响应：`errors[0].extensions = { "code": "BAD_USER_INPUT", "errorCode": "CONTENT_SUBMISSION_INVALID_PARAMS", "errorMessage": "退回时必须填写理由" }`。

**A3.4 `reviewContentSubmissionDecision`（RETURN）** — 变量：

```json
{ "input": { "submissionId": 1, "revisionId": 1, "decision": "RETURN", "comment": "请补充机型适配说明与校准判据。" } }
```

响应：`{ "submissionId": 1, "status": "RETURNED", "documentId": null }`。

**A3.5 `myContentSubmission(id: 1)`**（退回后）— 响应关键：`status: "RETURNED"`、`latestReview: { "decision": "RETURN", "comment": "请补充机型适配说明与校准判据。", "publishAttachment": false, "reviewedAt": "…" }`。

**A3.6 `contentSubmissionRevision(submissionId: 1, revisionNo: 1)`**（历史不可变）— 响应关键：`review: { "decision": "RETURN", … }`；`payloadSnapshot` 仍为 v1 内容（退回不改写历史版本）。

**A3.7 `updateContentSubmissionDraft(id: 1)`**（退回改稿）— 变量：

```json
{ "id": 1, "input": { "patch": { "contentText": "S7 样例正文 v2：1. 读取能量曲线并比对基线；2. 校准后复测；3. 归档记录。" } } }
```

响应：`{ "id": 1, "status": "RETURNED", "updatedAt": "…" }`。

**A3.8 `submitContentSubmission`（重提冻结 v2）** — 变量 `{ "id": 1, "input": { "libraryNoticeConfirmed": true } }`。
响应：`{ "submissionId": 1, "revisionId": 2, "revisionNo": 2, "status": "PENDING_REVIEW" }` → **记下 v2 `revisionId = 2`**。

**A3.9 `reviewContentSubmission(id: 1)`**（重提后）— 响应关键：`currentRevisionNo: 2`、`currentRevision.review: null`、`reviewHistory: [ { "revisionNo": 1, "decision": "RETURN", … } ]`（历史 1 条）。

#### A4 通过 / 发布 / 下载

**A4.1 `reviewContentSubmissionDecision`（APPROVE·发布附件）** — 变量：

```json
{ "input": { "submissionId": 1, "revisionId": 2, "decision": "APPROVE", "publishAttachment": true } }
```

响应：`{ "submissionId": 1, "status": "PUBLISHED", "documentId": 1 }` → **记下正式资料 `documentId = 1`**。

**A4.2 `myContentSubmission(id: 1)`**（发布后）— 响应关键：`status: "PUBLISHED"`、`publishedAt: "…"`、`latestReview: { "decision": "APPROVE", "publishAttachment": true, … }`、`publishedDocument: { "documentId": 1, "available": true }`。

**A4.3 `contentSubmissionRevision(submissionId: 1, revisionNo: 2)`** — 响应关键：`review: { "decision": "APPROVE", … }`、`payloadSnapshot` 为 v2 内容。

**A4.4 `reviewContentSubmission(id: 1)`**（审核历史）— 响应关键：`reviewHistory` 2 条，**新在前**：`[ { revisionNo: 2, decision: "APPROVE" }, { revisionNo: 1, decision: "RETURN" } ]`。

**A4.5 REST 下载正式附件** — `GET /api/content-submissions/1/attachments/1/download`。
响应：HTTP 200；`Content-Type: text/plain`；`Content-Disposition: attachment; filename*=UTF-8''s7-sample-attachment.txt`（RFC 5987，中文文件名不乱码）。

**A4.6 REST 终态移除被拒（失败样例）** — `DELETE /api/content-submissions/1/attachment`。
响应：HTTP **409**；信封 `data = { "statusCode": 409, "code": "CONTENT_SUBMISSION_STATE_NOT_EDITABLE", … }`。

**A4.7 `updateContentSubmissionDraft` 终态被拒（失败样例）** — 变量 `{ "id": 1, "input": { "patch": { "title": "S7 终态改稿" } } }`。
响应：`errors[0].extensions = { "code": "CONFLICT", "errorCode": "CONTENT_SUBMISSION_STATE_NOT_EDITABLE", "errorMessage": "当前状态的投稿不可编辑", "details": { "id": 1, "status": "PUBLISHED" } }`。

### 3.2 B 链：案例投稿与正式案例更正（FAULT_CASE）

> 工程师建稿送审（路径 A 与 A 链同夹具工程师；路径 B 用 `mock_engineer_chen`），管理员通过；随后管理员在资料库读取并执行案例更正（PR 6 消费口径）。

#### B1 案例草稿 → 发布

**B1.1 `createContentSubmissionDraft`（FAULT_CASE）** — 变量：

```json
{
  "input": {
    "kind": "FAULT_CASE",
    "fields": {
      "title": "S7 样例案例：送料机构周期性偏移",
      "equipmentModelId": 47,
      "errorCode": "E-S7-401",
      "phenomenon": "送料机构在连续运行后出现 0.05mm 周期性偏移。",
      "conditionText": "连续运行超过 2 小时。",
      "reproductionSteps": "1. 空载运行 2 小时；\n2. 测量送料定位偏差。",
      "handlingStatus": "UNRESOLVED"
    }
  }
}
```

响应：`{ "id": 2, "submissionKind": "FAULT_CASE", "status": "DRAFT" }` → **记下 `submissionId = 2`**。

**B1.2 `submitContentSubmission`（案例 v1）** — 变量 `{ "id": 2, "input": { "libraryNoticeConfirmed": true } }`。
响应：`{ "submissionId": 2, "revisionId": 3, "revisionNo": 1, "status": "PENDING_REVIEW" }` → **记下 v1 `revisionId = 3`**。

**B1.3 `reviewContentSubmissionDecision`（案例无附件通过）** — 变量：

```json
{ "input": { "submissionId": 2, "revisionId": 3, "decision": "APPROVE", "publishAttachment": false } }
```

响应：`{ "submissionId": 2, "status": "PUBLISHED", "documentId": 2 }` → **记下正式资料 `documentId = 2`**。要点：案例无附件时必须 `publishAttachment: false`（无文件版本传 `true` 会被拒）。

**B1.4 `myContentSubmission(id: 2)`**（案例发布后）— 响应关键：`faultCase` 12 字段（`handlingStatus: "UNRESOLVED"`、`diagnosis` / `actionTaken` / `resolution: null`、`equipmentModelId: 47`）、`material: null`、`currentAttachment: null`、`latestReview: { "decision": "APPROVE", "publishAttachment": false }`、`publishedDocument: { "documentId": 2, "available": true }`。

## 四、失败响应清单（真实捕获 + 组织权限口径）

| 样例步 | 触发 | 线上响应（真实） | 前端 `reason`（adapter 显式结果） |
| --- | --- | --- | --- |
| A2.3 | 送审未确认入库告知 | HTTP 200 + `code=BAD_USER_INPUT`；`errorCode=CONTENT_SUBMISSION_INVALID_PARAMS` | `invalid-input`（`submitContentSubmission`） |
| A2.5 | 待审中 REST 上传附件 | HTTP 409；`code=CONTENT_SUBMISSION_STATE_NOT_EDITABLE` | `state-conflict`（`uploadContentSubmissionAttachment`） |
| A3.3 | RETURN 缺 comment | HTTP 200 + `BAD_USER_INPUT`；`CONTENT_SUBMISSION_INVALID_PARAMS` | `invalid-input`（`reviewContentSubmissionDecision`） |
| A4.6 | PUBLISHED 后 REST 移除附件 | HTTP 409；`STATE_NOT_EDITABLE` | `state-conflict`（`removeContentSubmissionAttachment`） |
| A4.7 | PUBLISHED 后改稿 | HTTP 200 + `CONFLICT`；`STATE_NOT_EDITABLE`（含 `details.status`） | `state-conflict`（`updateContentSubmissionDraft`） |
| B3.4 | 非 FAULT_CASE 资料调用案例更正 | HTTP 200 + `BAD_USER_INPUT`；`REFERENCE_DOCUMENT_INVALID_PARAMS` | `invalid-input`（`updateReferenceDocumentCase`） |

组织权限口径（S7 自查修复后，前后端口径一致）：

- GraphQL：`ORGANIZATION_NO_ACTIVE_MEMBERSHIP` / `ORGANIZATION_AMBIGUOUS_MEMBERSHIP` → 大类 `FORBIDDEN`（前端 `forbidden`），**不得**当作会话失效。
- REST：同两码 → HTTP **403**（`rest-error-status.ts` 全局映射；投稿附件三端点与参考资料下载同口径）。
- 401 链：JWT 失效 → 前端声明会话失效（`onAuthFailure`），不吞成普通失败；REST 与 GraphQL 均为「刷新重试一次，仍失败宣布会话失效」。
- 生产环境 `errorCode` / `errorMessage` 可能被隐藏；前端生产分支只依赖稳定大类码（`extensions.code`）与 HTTP 状态。
