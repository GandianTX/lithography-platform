## 一、S7 交付范围与实现

### S7-1 content-submission 前端 feature（新增，`frontend/src/features/content-submission/`）

| 文件 | 内容 |
| --- | --- |
| `content-submission.types.ts` | 两类草稿写入/读取、审核详情、冻结版本、附件 REST 结果的全部公共类型（含 `ContentSubmissionUploadedAttachment` 等） |
| `infrastructure/content-submission-adapter.ts` | 9 个 GraphQL 函数：`fetchMyContentSubmissions` / `fetchMyContentSubmission` / `fetchContentSubmissionRevision` / `fetchReviewContentSubmissions` / `fetchReviewContentSubmission` / `createContentSubmissionDraft` / `updateContentSubmissionDraft` / `submitContentSubmission` / `reviewContentSubmissionDecision` |
| `infrastructure/content-submission-attachment-adapter.ts` | 3 个 REST 函数：`uploadContentSubmissionAttachment` / `removeContentSubmissionAttachment` / `downloadContentSubmissionAttachment`（`attachmentId` → `id` 归一；`filename*` 解析） |
| `index.ts` | feature 公共入口（barrel） |
| 两个 `.spec.ts` | 见第二节 |

- **错误契约双轨制**（A-PR0 §4.4-5）：auth/network/transport 复用现有 `GraphQLIngressError` 链路；业务拒绝返回显式失败结果（`reason` + 后端消息），生产分支只依赖稳定大类码 `extensions.code`，细码（`errorCode`）仅作可选细化——细码被隐藏时仍按大类正确落位。
- 附件 REST 与 GraphQL 同口径：`shared/http` 内 401 刷新重试一次，无刷新能力/刷新失败/重试仍 401 时宣布会话失效（`onAuthFailure`），不吞成普通失败。

### S7-2 `shared/http` 提升（新增，`frontend/src/shared/http/`）

- `rest-request.ts`：`fetchRestWithAuthRetry`（带鉴权 REST + 401 重试语义，Token 沿用 `configureGraphQLRuntime` 注入）。
- `rest-response.ts`：统一信封解析（`toRestErrorEnvelope` / `readRestErrorField`）与 `parseAttachmentFilename`（RFC 5987 `filename*`，缺失回落兜底名）。
- `rest-response.spec.ts`：4 用例。reference-document 附件链与投稿附件链**共用**该层，不再各自维护第二套。

### S7-3 reference-document 类型/adapter 扩展（13 个文件改动）

- `reference-document.types.ts`：新增读取字段（`organizationName` / `ingestMethod` / 列表 `caseHandlingStatus`）、`caseDetail` 明确可空（仅 FAULT_CASE）、`caseHandlingStatus` 筛选参数、`UpdateReferenceDocumentCasePatch`。
- `infrastructure/reference-document-adapter.ts`：`fetchReferenceDocuments` 增 `caseHandlingStatus` 筛选与列表新字段；`fetchReferenceDocument` 消费可空 `caseDetail` 与 `hasFile`；新增 `updateReferenceDocumentCase`（非案例资料按 `REFERENCE_DOCUMENT_INVALID_PARAMS` 落 `invalid-input`，**不是** `not-found`）。
- mock 适配器 / mock-data / UI 组件 spec 同步：普通资料缺失新字段不崩溃（既有页面组件兼容）。
